# 楚河汉界 · 在线象棋擂台

多人实时中国象棋对战平台：两人对弈、自由旁观、弹幕聊天。零第三方依赖，单个 Node.js 进程即可运行。

## 特性

- **完整棋规**：车马炮相仕帅兵卒走法、蹩马腿、塞象眼、白脸将、将军 / 将死 / 困毙判定，全部在服务端校验
- **多人对战**：创建棋室后分享链接，红黑双方实时落子，每步 90 秒限时，超时判负
- **专业棋谱**：每一手自动生成中式记谱（如「炮二平五」「马8进7」），含前/后同列棋子消歧，实时更新棋谱列表
- **观战模式**：座位坐满后仍可进入观战，观战人数实时展示
- **弹幕聊天**：棋手与观众的消息会以弹幕形式飘过棋盘
- **三款皮肤**：古木、墨玉、青瓷，棋盘与棋子配色随皮肤切换，选择保存在本地
- **实时同步**：基于 HTTP 长轮询，天然穿透各类代理，无需 WebSocket

## 本地运行

```bash
node server.js          # 默认 http://localhost:8000
PORT=3000 node server.js
```

## 目录结构

```
server.js          # HTTP 服务 + 棋规引擎 + 房间状态 + 长轮询
public/index.html  # 页面结构（大厅 / 棋室）
public/styles.css  # 视觉样式
public/app.js      # 棋盘绘制、交互、同步轮询、弹幕
build.sh / run.sh  # 部署适配脚本
```

## 说明

棋室与对局状态保存在服务进程内存中，进程重启后清空；适合轻量娱乐对局。
